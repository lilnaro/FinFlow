# FinFlow

Мобильное приложение для Android, которое помогает вести учёт личных доходов и расходов и получать советы по бюджету от встроенного ИИ-помощника.

Проект разрабатывается в рамках учебного курса по Android-разработке от компании "ПрофСофт". Приложение растёт вместе с курсом: от простого списка транзакций до полноценного приложения с интеграцией нейросетей.

## Идея

Большинство людей пользуется несколькими банковскими картами, и отслеживать все траты в разных приложениях крайне неудобно. FinFlow объединяет все доходы и расходы в одном месте. Приложение работает по принципу месячных циклов. В начале месяца пользователь задаёт стартовый бюджет, в течение месяца вносит транзакции (доходы и расходы), а в конце месяца всё сбрасывается и переносится в архив. Так удобно смотреть, как менялся бюджет от месяца к месяцу, не путаясь в старых данных.

## Основные экраны

**Главный экран**
Показывает сумму на начало месяца, текущий остаток и разницу в процентах. Ниже небольшой график из двух столбцов, сравнивающий стартовую сумму и остаток.

**Транзакции**
Список всех операций за месяц. Можно добавить новую транзакцию (сумма, категория, доход или расход) или удалить одну/несколько прямо из списка, отметив их чекбоксом.

**ИИ-ассистент**
Чат с подключённой языковой моделью, который анализирует историю трат и подсказывает, как оптимизировать бюджет.

**Новый месяц**
Закрывает текущий месяц, отправляет его в архив и предлагает ввести новый стартовый бюджет.

**Архив месяцев**
Список прошлых месяцев с краткой сводкой (стартовая сумма, конечная сумма, изменение в процентах). Можно открыть любой месяц и посмотреть все транзакции за него.

## Технологии

- Kotlin
- Jetpack Compose для интерфейса
- Room для локального хранения данных
- Retrofit для запросов к ИИ (OpenAI GPT / Google Gemini)
- Navigation Compose для переходов между экранами
